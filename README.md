# Справочник исследований

Тег `v0.1.0` фиксирует исходный HTML. Файлы для дальнейшей работы:

| Путь | Содержимое |
|---|---|
| `data/categories/01.json`–`09.json`, `water.json` | Карточки, нормативы, основания, отбор и прейскурант |
| `data/labels.json` | Названия разделов и видов исследований |
| `src/index.template.html`, `src/styles.css`, `src/app.js` | Разметка, оформление и поиск |
| `scripts/` | Проверка структуры и сборка |
| `research-directory-roadmap.md` | Дорожная карта |

Команды выполняются из корня репозитория на компьютере с Node.js. Сторонние пакеты для сборки не нужны.

```sh
node scripts/build.mjs --check
node scripts/build.mjs
```

Результат сборки — `dist/research-directory-sampling-trial.html`. Откройте его в браузере. Каталог, поиск и оформление находятся внутри файла. Режим предпросмотра без JavaScript получает карточки из того же каталога. Сборка не публикует сайт.

Исходный HTML в корне — копия первой версии. Для проверки новых изменений используйте файл из `dist/`.

Для ручной проверки найдите карточки `9.16.1.1`, `9.16.1.2.1` и `2.2.3`. Откройте микробиологию и отбор. Проверьте коды прейскуранта и одну строку пробоподготовки на группу.

## Тестовая PWA для iPhone

Команда `node scripts/build.mjs --pwa` собирает сайт в `dist/pwa/`.
Размещайте каталог целиком по HTTPS с сохранением структуры папок.
Для проверки добавьте сайт на экран «Домой», откройте его с иконки и
дождитесь сообщения «Справочник готов к работе без интернета».
Затем закройте приложение, отключите интернет и снова запустите его с иконки.
