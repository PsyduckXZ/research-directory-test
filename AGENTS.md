# Работа со справочником

- Создавайте ветку от `main` для каждой задачи и описывайте изменения в pull request.
- Правьте карточки в `data/categories/`, а названия разделов в `data/labels.json`.
- Для правки нормы, отбора или прейскуранта указывайте источник и контрольные карточки в pull request.
- Сохраняйте согласованные значения, единицы и условия при технической переработке. Пустые карточки и одинаковые коды разных карточек допустимы.
- Выполните `node scripts/build.mjs --check` и `node scripts/build.mjs`. При правке интерфейса или поиска проверьте контрольные карточки в собранном HTML.
- Файлы из `dist/` создаются при сборке. Исходный HTML первой версии доступен по тегу `v0.1.0`.
